# Brew House Cafe — React + Vite + Tailwind CSS

A responsive multi-page cafe frontend with reusable components, real Unsplash photography, a Pexels video background/gallery video, menu category filtering, mobile navigation, newsletter UI and a table-booking demo form.

## Pages
- Home (`/`)
- Our Story (`/about`)
- Menu (`/menu`)
- Gallery (`/gallery`)
- Contact & table request (`/contact`)

## Run locally
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Stack
React 18, Vite, React Router, Tailwind CSS 3, Lucide React, Google Fonts.

## Notes
- All images and the sample video load from external Unsplash/Pexels URLs, so internet access is required.
- Replace the sample cafe address, email, phone and social links with the real business details.
- The booking form, menu add action and newsletter are frontend demonstrations only; connect them to an API/backend to store submissions or send email.
- Every UI text/input size is 15px or larger; body copy and controls are 16px+.
